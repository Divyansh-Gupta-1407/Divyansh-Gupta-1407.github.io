// ABOUT THE PROJECT

What is it?

Ever used Google Docs and wondered how you can see your friends typing in real-time? This project is my take on exactly that!

It's a cloud-native platform built for teams to edit documents, share workspaces, and track who's online all at the same time. Under the hood, it's powered by modern event-driven microservices, which is a fancy way of saying it can handle a lot of people editing a lot of things really fast without crashing.
