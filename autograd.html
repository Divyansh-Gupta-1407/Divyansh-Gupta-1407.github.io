Neural Network from Scratch in C++

// ABOUT THE PROJECT

What is it?

If you've ever used PyTorch or TensorFlow, you know they do a lot of heavy mathematical lifting for you. I wanted to see what happens under the hood, so I built my own version entirely from scratch using C++!

It's a minimal engine that understands computational graphs and can automatically calculate derivatives (the hard math required for AI to "learn"). It proves that you don't always need massive libraries to build and train a neural network—sometimes just a solid understanding of calculus and raw C++ is enough!
