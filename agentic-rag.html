Agentic RAG.

Multi-Agent Enterprise Knowledge & Analytics Engine

// ABOUT THE PROJECT

What is it?

Imagine a standard chatbot, but instead of just guessing answers, it actually has a team of specialized mini-bots (agents) working for it behind the scenes.

When you ask a complex question, a "Router Agent" acts like a manager, figuring out if it needs to dig through documents, run a database query, or both. It then sends its agents to do the hard work, gather all the right information, and synthesize a perfect, accurate response for you. It's built using Python and LangGraph to make sure everything runs smoothly!
