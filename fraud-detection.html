What is it?

Nobody likes getting scammed. This project is a Machine Learning pipeline dedicated to acting like a digital security guard.

It takes in huge amounts of transaction data, looks for sneaky patterns that humans might miss, and flags the bad actors instantly. Built with Python and Scikit-learn, it cleans up messy data, trains itself on past frauds, and then stays on the lookout to predict and catch any suspicious future transactions!
